Connect to IRIS

Credentials are sent only to the selected IRIS instance. Passwords are cleared after each attempt. Access and refresh tokens stay in page memory only and are never written to the operation journal.

Native logs use a separate, read-only IRIS extension on this instance. Your account needs the IRIS operating permission and read access to the installation namespace. If the extension is unavailable, other workspaces still connect.
